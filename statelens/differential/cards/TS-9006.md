## Statement
While the replica's verification of a digest that names no block has registered a local
wait and its requester has gone away, the replica keeps the wait as registered and has
issued no fetch of any kind.

## Rationale
Verification waits only for local delivery, and cancelling its requester must not turn the
wait into a fetch or register a new wait. A regression that falls back to fetching on
cancellation, or re-subscribes, shows in this state, which is defined by pending work that
was neither answered nor closed when the requester left.

## Evidence
The source test calls verify for the hash of a literal, observes the local wait and the
empty fetch history, drops the verify receiver, and asserts the fetch history is still
empty (consensus/src/marshal/standard/mod.rs:2839-2900@392b116687). The scenario prefix the
differential test compares against is `StandardVerifyMissingCandidateWaitsWithoutFetching`
(consensus/fuzz/marshal/src/scenarios/scenarios.rs:678-766@392b116687).

## History
E1. harness: calls B's verify for the digest m, which names no block, at view v on
    genesis, led by B.
    Check (B, v, m): B's verification of m at v is requested.
E2. B: registers a local wait for m and issues no fetch of any kind; the verification
    stays pending.
    Check (B as E1, v as E1, m as E1): B holds a local wait for m, B's fetch history is
    empty, B issued no targeted fetch and B's verification of m at v is pending.
E3. harness: drops the pending verification's receiver.
    Check (B as E1, v as E1, m as E1): the receiver of B's verification of m at v is
    dropped.
E4. B: keeps the wait and issues no fetch.
    Holds (B as E1, v as E1, m as E1): B's local wait for m is the one registered, B's
    fetch history is empty, B issued no targeted fetch and the verification's receiver
    stays dropped.

        &self,
        harness: &mut FuzzScenarioStandardHarness<P, M>,
    ) -> ScenarioHandoff<P> {
        harness.begin("test_standard_verify_missing_candidate_waits_without_fetching");
        // The unknown candidate: a digest that names no block, in a view-1
        // context on genesis led by the source's `me` (Node::B under the
        // participant permutation), built as in the source.
        let genesis_digest = harness.genesis().digest();
        let round_one = round(1);
        let consensus_context = harness.context(round_one, Node::B, View::zero(), genesis_digest);
        let missing = Sha256::hash(&[b"missing candidate"]);

        // Source order: `verify` first, then the local wait is observed. The
        // wait count is captured before `verify` so the barrier-poll below
        // cannot race the wrapper's registration.
        let waits_before = harness.buffer_subscription_count(Node::B);
        let mut verify = harness
            .wrapper_verify(Node::B, consensus_context, missing)
            .await;
        let mut rounds_waited = 0;
        while harness.buffer_subscription_count(Node::B) == waits_before {
            rounds_waited += 1;
            assert!(
                rounds_waited <= 64,
                "unavailable candidate verification never registered a local wait"
            );
            let _ = harness.barrier(Node::B).await;
        }
        assert!(
            harness.targeted_is_empty(Node::B),
            "unavailable candidate verification must not issue targeted fetches"
        );
        assert!(
            matches!(verify.try_recv(), Err(TryRecvError::Empty)),
            "unavailable candidate verification must remain pending"
        );

        // The source drops the pending verify receiver: cancellation must
        // not convert the local wait into a fetch or register a new wait
        // (the counter counts registrations, so equality rules out a
        // cancel-triggered re-subscription; the handoff multiset carries the
        // source's post-drop no-fetch assertion).

        drop(verify);
        let _ = harness.barrier(Node::B).await;
        assert_eq!(
            harness.buffer_subscription_count(Node::B),
            registered_waits,
            "canceling a missing candidate wait must not register a new wait"
        );
        assert!(
            harness.targeted_is_empty(Node::B),
            "canceling a missing candidate wait must not issue targeted fetches"
        );

        ScenarioHandoff {
            engine_floor: Floor::Genesis(genesis_digest),
            engine_journal: Vec::new(),

            reference_chain: Vec::new(),
