## Statement
While the replica has signed a nullify vote for view v and holds a notarization of a proposal
for v, the replica is certifying that proposal.

## Rationale
A nullify vote and a notarization of the same view meet whenever the replica times out in a view
before it sees the proposal that the other replicas notarize. The replica must still certify the
notarized proposal, because certification decides whether it may leave the view through that
notarization; its nullify vote only forbids it to sign a finalize vote for the view. A replica
that refuses or abandons that certification after its nullify vote stalls in the view, and one
that signs a finalize vote for it after certifying signs both votes for one view. This is a smoke
card: a short History of common events, which a scaffold should reach on its canonical input, so
that a miss points at the scaffold or the harness rather than at the protocol.

    /// Returns the proposal once a notarization exists for it.
    pub fn try_certify(&mut self) -> Option<Proposal<D>> {
        let notarization = self.notarization.as_ref()?;
        match self.certify {
            CertifyState::Ready => {}
            CertifyState::Outstanding(_) | CertifyState::Certified(_) | CertifyState::Aborted => {
                return None;
            }
        }

        // The proposal must match the notarization's proposal (which
        // is overwritten, regardless of our own initial vote, during
        // processing).
        let proposal = self
            .proposal
            .proposal()
            .cloned()
            .expect("proposal must be set if notarization is set");
        assert_eq!(
            &proposal, &notarization.proposal,
            "slot proposal must match notarization proposal"
        );
        Some(proposal)
    }

    /// Returns a nullify vote if we should timeout/retry.
    ///
    /// Returns `Some(true)` if this is a retry (we've already broadcast nullify before),
    /// `Some(false)` if this is the first timeout for this round, and `None` if we
    /// should not timeout (e.g. because we have already finalized).
    pub const fn construct_nullify(&mut self) -> Option<bool> {
        if self.decision.is_finalize() {
            return None;
        }
        let retry = self.decision.is_nullify();
        self.decision = Decision::Nullify { retry: None };
        Some(retry)
    }
