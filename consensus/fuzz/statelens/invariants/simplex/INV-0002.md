## Statement
When the replica assembles a notarization, nullification or finalization certificate from
votes, the replica shall include at most one vote from each participant in that certificate.

## Rationale
A certificate proves that a quorum of distinct participants signed the same message. A signer
that appears twice adds no extra support, and the replica's certificate code treats a repeated
signer as a broken precondition: in the issue it panicked. A Byzantine participant can always
send the same signed vote more than once, and a peer can relay a vote more than once. The replica
must therefore collapse repeated votes per signer, kind and view before assembly, on every path
that feeds assembly: network votes, its own votes, and votes replayed from the journal after a
restart.

## Evidence
Issue #2070 ("panic if there are several votes from one signer"): in a Twins-style test, two
validators ran with the same key and cast the same notarize vote for the same proposal in view 5.
Another honest replica collected the list [signer 3, signer 3, signer 4], treated it as a quorum
of 3, and called notarization assembly, which panicked with "duplicate signer index: 3". The
maintainers confirmed that consensus must never pass duplicate votes to certificate assembly
("we skip duplicates in batcher"; the voter also dedups replayed votes). The issue was closed by
PR #2102 (merge commit 6ca07aba2fee6a37c166885abc94724c77f0b679), which made committee keys
unique by construction.

## Preconditions / assumptions
Covers votes from any source, including the replica's own votes, duplicate network deliveries,
and votes reinserted from the journal during recovery.

## Observation hints
Certificate assembly in the batcher verifier (`try_construct_notarization`,
`try_construct_nullification`, `try_construct_finalization`) and the scheme's
`assemble` path, which returns `AssemblyError::DuplicateSigner`. Per-signer tracking is in
`VoteTracker` in `actors/batcher/round.rs`. Check the signer indices of the votes passed to
assembly and of the resulting certificate's signer set.
