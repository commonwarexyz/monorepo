    \node[panel,right=.42cm of rootfields,text width=6.15cm,minimum height=1.24cm] (witness) {\textbf{One 2 KiB slot}\\\scriptsize 92 B root + 16 B witness envelope\\+ $\leq$1,940 B local link / unused space};

  \vspace{0.3cm}
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.32\textwidth}
      \eyebrow{Append}\par\smallskip
      \small Write through immediately at the byte's final file offset.
    \end{column}
    \begin{column}{0.32\textwidth}
      \eyebrow{Publish}\par\smallskip
      \small Alternate root slots; generation parity preserves the immediate fallback.
    \end{column}
    \begin{column}{0.32\textwidth}
      \eyebrow{Recover}\par\smallskip
      \small Read bounded roots and, only for an unresolved epoch, checksum a bounded suffix.
    \end{column}
  \end{columns}

  \vfill
  \takeaway{No extent map, hole punching, or compaction: a root selects a reachable payload prefix.}

  \note{UNO is a development nickname, not a new public acronym: it reflects the one payload write and one hot-path barrier target. Both alternating 2 KiB slots share one 4 KiB mutable page after the immutable header. They are disjoint addressed ranges: generation parity writes one while preserving the other as fallback under the old/new/subset-of-addressed-write model. Collateral corruption of the containing physical block is a stronger media-failure model and is not made atomic by this layout. The application gets 64 tag bytes. The checked-page wrapper exposes 60 as its marker and reserves four for the partial-page checksum; contiguous currently uses the marker's first eight bytes for its start authority.}
\end{frame}

  \vfill
  \takeaway{\textbf{In progress:} CRC in RAM \quad \textbf{At sync:} root + local witness slot \quad \textbf{Never at sync:} rewrite payload.}

  \note{This is the complete small-write story on one slide. A ten-byte append writes ten payload bytes at their final offset. AtomicWriter computes the CRC of the entire current partial page and passes it in the last four application-tag bytes to append-tagged; that method stages length and tag as one in-memory mutation. Sync writes the next root generation, witness envelope, and any local ring link into the alternate 2 KiB slot. The lower bar expands only the 92-byte root header, with widths proportional to bytes. No checksum bytes appear after A or B. The prior root remains the fallback, and each root header has its own CRC, so an arbitrary torn candidate is rejected. Once P logical bytes accumulate, AtomicWriter appends one four-byte footer. Any remainder becomes the next tail and its CRC moves into the selected root. The footer makes that completed payload page immutable and eligible for the planned page cache. This is storage-page integrity, not an application record checksum or item-boundary map.}

    \begin{column}{0.48\textwidth}
      \eyebrow{A possible bridge}
      \scriptsize
      \begin{itemize}\setlength\itemsep{0.03cm}
        \item Accept caller-supplied spans; return composable \texttt{(offset, len, CRC32C)} receipts.
        \item Combine CRCs across write/preflush chunks without rereading bytes.

      \scriptsize

      \end{itemize}

  \vfill
  \takeaway{Promising direction: share checksum computation, while callers retain ownership of logical boundaries.}

  \note{UNO currently needs only one CRC over the not-yet-proven-durable suffix. A useful experiment would let contiguous provide a boundary plan and consume receipts while keeping codecs and indexes out of the blob layer.}

  \vspace{0.06cm}
  \centering\scriptsize Under the fault model, any subset of unsynced overwrite bytes may survive; rollback therefore needs retained old bytes or a separate new copy.

  \vfill
  \takeaway{CRC detects but cannot restore overwrites. Composite V2 keeps overwrite-heavy indexes ordinary behind atomic authority.}

  \note{This is the important distinction behind \textit{convert all}. Converting a composite store's commit boundary does not require AtomicBlob to support arbitrary overwrite. The Freezer table and Ordinal can remain ordinary files: write their future epoch, make them durable, then publish the V2 journals and archive authority. Truly converting every physical file would require retaining overwritten bytes somewhere. Copy-on-write turns the file into a page-mapped store; undo logging writes old data again; a volume layer centralizes allocation and recovery. Each gives rollback material but reintroduces the write amplification, metadata, garbage collection, or global coordination that append-only UNO intentionally avoids.}
\end{frame}
